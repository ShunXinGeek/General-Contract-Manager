# 合同查询系统 OVERVIEW

## 项目概述

本项目为香港建造业 GCC/SCC 双层合同文件的查询系统。当用户提出与建造合同相关的问题时，按本文档定义的规则进行条款查询和解答。

## 文件清单

| 文件 | 路径 | 用途 |
|------|------|------|
| GCC 原文 | `projects/contracts/GCC.md` | 通用合同条件，基准文本 |
| SCC 原文 | `projects/contracts/SCC.md` | 特别合同条件，修改令 |
| 交叉索引 | `projects/contracts/cross-reference.md` | 主题关键词 → 条款编号映射，标注 SCC 是否有修改 |

## 查询逻辑与流程

### 双层文件体系

| 文件 | 角色 | 效力 |
|------|------|------|
| GCC | 通用合同条件（基准文本） | 默认适用 |
| SCC | 特别合同条件（修改令） | **优先于 GCC** |

### 查询步骤

```
用户问题 → 提取主题关键词
         → 查 cross-reference.md 索引表，匹配关键词 → 定位 GCC 条款编号
         → 查看索引表第三列，判断 SCC 是否对该条款存在修改
            → 有 SCC 修改？以 SCC 为准（删除/替换/补充）
            → 无 SCC 修改？以 GCC 为准
         → 输出最终有效内容
```

### 详细执行步骤

1. 先看 `cross-reference.md` 中的索引表，根据用户问题的主题关键词匹配 GCC 条款标题
2. 确认 SCC 是否有对应条款修改（索引表第三列）
3. 如有 SCC 修改：用 Grep 在 `projects/contracts/SCC.md` 中搜索对应 SCC 条款编号，读取完整原文
4. 如无 SCC 修改：用 Grep 在 `projects/contracts/GCC.md` 中搜索对应条款编号，读取完整原文
5. 回答时先给结论，再列出条款原文，如有 SCC 修改需明确标注"以 SCC 为准"

## 关键背景

- 本合同 Employer 为医院管理局（Hospital Authority），非政府
- SCC 中有约 40 条标记为 "(Not used)"，直接忽略
- SCC 对 GCC 的修改有五种形式：新增、删除替换、修改/扩展、间接引用、无修改
- 原始 GCC 有 90 条条款，SCC 约 130 条特别条款
